## 😤 Боль клиента

Диспетчер собирает заявки по телефону, монтажник «отчитывается» в переписке, а руководитель узнаёт о просрочке, когда акт не закрыт третий день. Никто не видит, **кто где сейчас находится и что именно не сделано.**

## ✅ Что даёт FieldOps

- **Диспетчерская** — заявки в таблице с фильтрами, назначение, приоритет, адрес, слот времени.
- **Мои выезды** — у специалиста только свои заявки: маршрут на день, чек-лист, фото, кнопка закрытия.
- **SLA-таймер** — обратный отсчёт и красный блок просроченных заявок на дашборде.
- **Акт** — номер, сумма работ, материалы, отметка «подписан клиентом».
- **PWA** — ставится на Android и iOS, открывается офлайн после первого визита.

## 🔑 Возможности MVP

- Заявка: клиент, телефон, адрес, тип работ, приоритет, слот, исполнитель, описание
- Статусы `new → assigned → onway → onsite → done → closed` + отмена с причиной
- Чек-лист работ с прогрессом в процентах — **«Выполнена» недоступна, пока не отмечено 100 %**
- Фотоотчёт с превью, акт с суммой и подписью — **закрыть акт без суммы нельзя**
- SLA: расчёт времени до дедлайна, подсветка просрочки в отдельном блоке дашборда
- Дашборд: счётчики по статусам, нагрузка специалистов, сумма закрытых актов
- Фильтры и поиск, данные сохраняются после перезагрузки, экспорт CSV/JSON
- PWA: `manifest.webmanifest` + service worker

## 👥 Роли и доступ

| Роль | Что может | Что не может |
|---|---|---|
| **Диспетчер** | создаёт заявки, назначает и переназначает, контролирует SLA | не закрывает акты за специалиста |
| **Специалист** | видит только свои заявки, статус, чек-лист, фото, акт | не видит и не правит чужие заявки |
| **Руководитель** | дашборд, нагрузка, просрочки, стоимость, выгрузки | не меняет чек-листы на месте |
| **Администратор** | пользователи, справочники, интеграции | — |

Проверка прав вынесена в функции `canEdit()` / `canSee()`: кнопка не появится у роли, которой она не положена — даже если править DOM.

## 🎬 Что потрогать в живом демо

1. Откройте **Диспетчерскую** и создайте заявку — она сразу появится у специалиста в «Моих выездах».
2. Переключитесь на роль **Специалист** — чужие заявки исчезнут из списка.
3. Попробуйте закрыть заявку, не отметив чек-лист — система не даст.
4. Попробуйте закрыть акт без суммы — блокировка.
5. Обновите страницу: данные и фото останутся на месте.

## 🛠 Технологии

| Область | Решение |
|---|---|
| Стек | HTML5 · CSS3 · JavaScript (ES6), без фреймворков и сборки |
| Хранение | `localStorage`, демо-данные предзаполнены |
| PWA | `manifest.webmanifest` + `sw.js`, офлайн после первого визита |
| Фото | `dataURL` в MVP (без сервера, лимит ~5 МБ) |
| Доступность | кнопки от 44 px, статус не только цветом, но и текстом |
| Адаптив | от 360 px (телефон в поле) до десктопа |
| Интеграции | заглушка вебхука Битрикс24 с описанием полей сделки |
